# exoplanets: Access NASA's Exoplanet Archive Data

The goal of exoplanets is to provide access to NASA's Exoplanet Archive
TAP Service. For more information regarding the API please read the
documentation <https://exoplanetarchive.ipac.caltech.edu/index.html>.
